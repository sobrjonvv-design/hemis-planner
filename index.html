Подключение и анализ HEMIS (Расписание + НБ)

Даже если вставить ссылку со страницей `/dashboard/login`, сайт сам выделит нужный домен.
Токен можно получить через `/rest/v1/auth/login` или скопировать из вкладки Network в браузере.
Если сервер вашего вуза закрыт снаружи, просто вставьте сюда JSON расписания из HEMIS.
Загружает одновременно расписание (`/rest/v1/education/schedule`), пропуски НБ (`/rest/v1/education/attendance`) и учебные часы (`/rest/v1/education/subjects`).

📱 Установка на телефон / компьютер (PWA)

После загрузки на GitHub Pages вы можете установить HEMIS Planner как полноценное приложение с иконкой на главный экран:

  • На Android (Chrome): меню ⋮ → «Установить приложение» или «Добавить на гл. экран».
  • На iPhone (Safari): кнопка «Поделиться» (квадрат со стрелкой вверх) → «На экран „Домой“».
  • На ПК (Chrome / Edge): значок установки ⊕ справа в адресной строке браузера.

Облачная синхронизация (ПК ↔ Телефон)

Синхронизируйте ваше расписание, пропуски «НБ» и задания между компьютером и телефоном по простому ID и паролю (без токенов и регистрации!).

Как пользоваться:
1. На компьютере введите ваш ID и придумайте пароль, затем нажмите «⬆ Отправить в облако».
2. На телефоне откройте сайт, введите те же самые ID и пароль и нажмите «⬇ Загрузить из облака» — всё расписание и задания сразу появятся!
