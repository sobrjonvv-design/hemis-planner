# HTTPS-мост HEMIS Planner

Это серверная часть для входа в HEMIS с сайта на GitHub Pages и телефона. **Загрузка этой папки в GitHub не запускает сервер.** Worker необходимо отдельно развернуть в своём Cloudflare-аккаунте.

Для настройки через браузер откройте `bridge-setup.html` в корне опубликованного сайта. Там есть копирование кода, генератор отдельного ключа и инструкция для пользователя без аккаунта Cloudflare. Регистрацию и принятие условий провайдера пользователь выполняет самостоятельно.

При подключении GitHub укажите корневую папку `cloud-bridge`, оставьте команду сборки пустой, а команду публикации — `npx wrangler deploy`. В `wrangler.jsonc` задано имя `hemisjon`, соответствующее созданному Worker. Для другого Worker замените поле `name` его точным именем. Загрузите папку `cloud-bridge` целиком, сохранив её структуру; не переносите её файлы в корень сайта.

## Настройки сервера

- `BRIDGE_KEY`: Secret длиной 24–256 символов, лучше 64 случайных шестнадцатеричных символа. Не пароль HEMIS. Не помещайте его в GitHub, worker.js или wrangler.jsonc.
- `ALLOWED_ORIGINS`: строка origin, разрешённых для браузера, разделённых пробелами или запятыми. Например `https://sobrjonvv-design.github.io`. Путь `/Hemisjon/` и завершающий слеш не нужны. Укажите точный origin своего опубликованного сайта. Поддомены автоматически не разрешаются.
- `ALLOWED_HOSTS`: необязательные дополнительные домены порталов, через запятую. По умолчанию разрешены шесть вузов из приложения. Произвольные адреса и маршруты не поддерживаются.

Сервер работает только после настройки ключа и списка origin. `GET /health` не требует ключа, не пересылает запрос в HEMIS и возвращает только готовность моста. `POST /hemis-proxy` принимает `text/plain` с JSON-объектом `{key,target,method,token,body}`. Нестандартные заголовки клиента не нужны. Ключ проверяется до запроса к вузу. Только четыре заранее определённых маршрута HEMIS разрешены; перенаправления не выполняются.

## Сайт

Откройте «Подключить HEMIS», выберите «HTTPS-мост», введите адрес развернутого Worker и ключ. Нажмите «Проверить подключение». После проверки можно войти в HEMIS. Сайт запоминает адрес сервера; ключ, пароль и Bearer-токен остаются только в памяти сеанса. Удалённый режим не пытается автоматически отправлять их через локальный или публичный прокси.

## Ограничения

Cloudflare должен иметь сетевой доступ к вузу. Если портал блокирует его IP, требует другой API или недоступен извне Узбекистана, потребуется сервер в разрешённой сети. Успешный `/health` не подтверждает вход в HEMIS. Код сам не регистрирует аккаунт, не публикует Worker и не исправляет Geo-IP. Реальные учётные записи не использовались в разработке.

Журналы запросов/ответов в коде отсутствуют; в wrangler.jsonc отключено observability. Провайдер инфраструктуры может хранить служебные метаданные. Не добавляйте логирование логинов, паролей, ключей или ответов API. Используйте только собственный мост либо мост доверенного владельца. Встроенное ограничение 40 запросов в минуту на IP действует в пределах экземпляра Worker, а не как глобальная распределённая квота.
