# 🎓 HEMIS Planner — Умный анализатор расписания и заданий студента

Персональный веб-сайт для студентов вузов Узбекистана (система **HEMIS**), который:
1. **Анализирует расписание из вашего аккаунта HEMIS** (`/rest/v1/auth/login` и `/rest/v1/education/schedule`) или работает в ручном/демо-режиме.
2. **Показывает, в какие дни недели у вас есть занятия**, сколько пар в каждый день и какие дни свободны.
3. **Прямо под каждым предметом в расписании дня недели показывает список ваших заданий** (СРС, лабораторные, домашние работы, рубежные контроли), которые нужно подготовить к этому предмету в этот день недели.
4. **Сообщает о ближайших парах и дедлайнах** в блоке «Сегодня и Завтра».
5. **Синхронизирует данные между компьютером и телефоном** через бесплатное облако **GitHub Gist** или **Firebase Realtime Database**, а также мгновенно сохраняет всё в браузере (`localStorage`).

## 🚀 Как загрузить сайт на GitHub и включить GitHub Pages

Проект написан на чистом современном **HTML5 + CSS3 + ES Modules JavaScript** без необходимости сборки, поэтому он работает на **GitHub Pages** сразу после загрузки!

### Шаг 1. Загрузка кода в ваш GitHub репозиторий
Откройте терминал в папке проекта и выполните:
```bash
git init
git add .
git commit -m "Initial commit: HEMIS Planner"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/hemis-planner.git
git push -u origin main
```

### Шаг 2. Включение бесплатного хостинга GitHub Pages
1. Перейдите в ваш репозиторий на GitHub.
2. Откройте вкладку **Settings** → в меню слева выберите **Pages**.
3. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
4. Выберите ветку **`main`** и папку **`/ (root)`**, затем нажмите **Save**.
5. Через 1 минуту ваш сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/hemis-planner/`

## ☁️ Как настроить синхронизацию между телефоном и ПК (GitHub Gist)

Чтобы задания, которые вы записали на компьютере, сразу появлялись на телефоне:
1. В вашем аккаунте GitHub перейдите в **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token**.
2. Отметьте галочку **`gist`** (Create gists) и скопируйте созданный токен (`ghp_...`).
3. На сайте **HEMIS Planner** нажмите кнопку **«Облако»** в правом верхнем углу.
4. Вставьте ваш токен и нажмите **«⬆ Отправить в облако»** — сайт автоматически создаст приватный Gist и покажет его **Gist ID**.
5. На телефоне откройте ваш сайт, нажмите **«Облако»**, введите тот же токен и **Gist ID**, после чего нажмите **«⬇ Загрузить из облака»**.

## 📂 Структура проекта

- `index.html` — главная страница (дашборд, расписание по дням недели, встроенные блоки заданий под каждым предметом, модальные окна).
- `css/styles.css` — адаптивные стили с поддержкой тёмной и светлой темы.
- `js/hemis.js` — модуль работы с REST API HEMIS (`/rest/v1/auth/login`, `/rest/v1/education/schedule`), обход CORS и нормализация расписания по дням недели.
- `js/storage.js` — модуль хранения данных (`localStorage`, синхронизация через GitHub Gist API и Firebase Realtime Database, экспорт/импорт `.json`).
- `js/app.js` — логика интерфейса, привязка заданий к предметам и дням недели, умные оповещения на сегодня и завтра.
