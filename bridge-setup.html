Вход с GitHub и телефона

GitHub Pages показывает сайт, но не запускает серверный код. При запрете CORS со стороны HEMIS нужен отдельный HTTPS-мост. Эту настройку достаточно выполнить один раз.

Сначала настройте свой мост. Для проекта Hemisjon код уже опубликован по адресу https://hemisjon.sobrjonvv.workers.dev. Если личный ключ ещё не добавлен, перейдите к шагу 03. Если он уже настроен — к шагу 04. Для собственной копии сайта выполните все шаги ниже в своём аккаунте Cloudflare.

01Создайте аккаунт Cloudflare

Откройте регистрацию, создайте свой аккаунт и подтвердите почту. Регистрацию и принятие условий выполните самостоятельно.

Открыть Cloudflare →

Логин и пароль Cloudflare, пароль HEMIS и ключ сервера не нужно присылать в чат.

02Создайте Worker и вставьте код

В панели Cloudflare откройте Workers & Pages → Create application. Выберите шаблон Hello World, задайте имя, например hemis-planner-bridge, и опубликуйте. Затем откройте Edit code, замените пример кодом ниже и нажмите Deploy.

Если удобнее импортировать GitHub-репозиторий

Подключите репозиторий с сайтом, укажите корневую папку cloud-bridge, оставьте сборку пустой и используйте команду публикации npx wrangler deploy. Загрузите папку cloud-bridge целиком, сохранив её структуру. В её wrangler.jsonc указано имя hemisjon: оно должно совпадать с именем Worker в Cloudflare. Для другого Worker замените поле name. После публикации всё равно добавьте секрет и разрешённый адрес из следующего шага.

03Настройте две переменные

В вашем Worker откройте Settings → Variables and Secrets → Add. Добавьте обе записи и сохраните через Deploy.

ИмяТипЗначение
BRIDGE_KEYSecretОтдельный ключ, созданный ниже
ALLOWED_ORIGINSTextOrigin опубликованного сайта без пути репозитория

Ключ создаётся только в этом браузере. Страница его никуда не отправляет и не сохраняет. Вставьте одно и то же значение в Secret BRIDGE_KEY и затем в форму Planner.

04Подключите адрес сервера к Planner

Cloudflare покажет адрес вида https://hemis-planner-bridge.ВАШ-ПОДДОМЕН.workers.dev. Вернитесь в Planner → Подключить HEMIS, выберите HTTPS-мост, вставьте адрес и ключ сервера и нажмите Проверить подключение.

Когда мост станет доступен, поля HEMIS разблокируются. Выберите TIFT и войдите своим обычным ID и паролем. Ключ моста — отдельный ключ, не пароль HEMIS.

Если мост доступен, но HEMIS не отвечает

Cloudflare выполняет запрос со своего сервера. Если вуз ограничивает доступ по стране/IP или REST API недоступен, один CORS-мост этого не устранит. Тогда нужен мост на сервере с доступом к порталу — например в сети Узбекистана — либо локальная версия через start.bat и последующая синхронизация данных с телефоном.

Сервер не записывает логины, пароли, токены или ответы HEMIS в журнал. Не добавляйте такое логирование самостоятельно. Разворачивайте код в своём аккаунте: владелец сервера и провайдер инфраструктуры технически обрабатывают передаваемые данные.
